# Specialist Planner v0.5.0 — First Stable Classroom Release

Released 5 September 2026.

This milestone follows real classroom trial and establishes the stable single-teacher workflow.

- Use **Week** as the progress-aware daily teaching workspace.
- Review independent class positions and cohort exceptions in **Progress**.
- Record **Completed**, **Partial** and **Not taught** without accidental double advancement.
- Browse confirmed outcomes, notes and reasons in **History**.
- Open linked Unit Library teaching content without making Planner progress depend on resource availability.
- Keep ownership of classroom planning data locally, with complete JSON backup and restore.

v0.5.x is the stable single-teacher baseline. Shared Programs, co-teaching, CRT access and cloud architecture remain future work.
